# 1. What is JavaScript?
JavaScript (JS) is a high-level, interpreted, lightweight, object-oriented, and dynamically typed programming    language used to make web pages interactive.

It is one of the three core technologies of web development:
HTML → Structure
CSS → Styling
JavaScript → Functionality & Interactivity


2. History
- Created by Brendan Eich
- Developed in 1995
- Initially named Mocha
- Renamed to LiveScript
- Finally renamed to JavaScript

4. Features of JavaScript
- High-Level Language
- Lightweight
- Interpreted
- Object-Oriented
- Prototype-Based
- Dynamically Typed
- Cross Platform
- Event Driven
- Case Sensitive
- Multi-Paradigm
- Supports Functional Programming
- Supports Asynchronous Programming

# 5. JavaScript is a dynamically typed language.
JavaScript is a dynamically typed language because variable types are determined at runtime, and a variable can store values of different data types without explicit type declarations.


6. JavaScript is Interpreted
- JavaScript executes line by line.
- Today, browsers use JIT (Just-In-Time Compilation) to make execution much faster.

7. JavaScript Engine
Every browser has a JavaScript engine.
Examples
- Chrome → V8 Engine
- Edge → V8
- Firefox → SpiderMonkey
- Safari → JavaScriptCore
The engine converts JavaScript code into machine code.

8. Ways to Add JavaScript
- Inline
ex-  <button onclick="alert('Hello')">Click</button>

- Internal
ex-  <script>console.log("Hello"); </script>

- External
ex- <script src="script.js"></script>
