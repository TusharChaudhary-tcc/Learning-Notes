# Fork

Fork creates a copy of someone else's GitHub repository into your GitHub account.

```
Original Repository
        │
        ▼
      Fork
        │
        ▼
Your Repository
```

Main use:

- Open Source Contribution
- Experimenting safely
- Learning from existing projects

---

# Fork vs Clone

Fork

- Creates a copy on GitHub.
- Used before contributing to open source.

Clone

- Downloads a repository to your computer.

Usually:

```
Fork
   ↓
Clone
   ↓
Code
   ↓
Commit
   ↓
Push
   ↓
Pull Request
```
